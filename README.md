# LegalTech

Aplicación móvil Android desarrollada en **Kotlin** y **Jetpack Compose** enfocada en orientación y herramientas jurídicas, con módulos como derecho laboral, derechos de petición, tutelas, servicios públicos de consumo, consulta de plazos y asistente.

## Características principales
- **Interfaz en Jetpack Compose:** Pantallas diseñadas para una navegación clara y rápida desde dispositivos Android.
- **Módulos de orientación y consulta:** Acceso organizado a secciones de peticiones, tutelas, temas laborales, servicios de consumo, plazos y historial.
- **Asistente integrado:** Apoyo interactivo dentro de la aplicación.

## Tecnologías utilizadas
- **Lenguaje:** Kotlin
- **UI:** Jetpack Compose / Material Design
- **Entorno:** Android Studio
